# Discord-бот для сервера — инструкция для новичка

Бот умеет:
- **Модерация**: `/kick`, `/ban`, `/unban`, `/mute`, `/unmute`, `/warn`, `/warns`, `/clear`
- **Роли**: `/give_role`, `/remove_role`, `/reaction_role_setup` (роль по реакции на сообщение) + автороль новым
- **Казна/донаты**: `/donate`, `/treasury`, `/top_donators`, `/my_donations`
- **Развлечения**: система уровней за активность, `/level`, `/leaderboard`, `/dice`, `/coinflip`, `/poll`
- **Приветствия**: сообщение при входе/выходе участника

Всё общение с ботом — через слэш-команды (начинаются с `/`), они появятся
сами в Discord после запуска бота, писать их руками не нужно — Discord сам
подскажет и покажет описание.

---

## Шаг 1. Создать бота в Discord Developer Portal

1. Зайди на https://discord.com/developers/applications
2. Нажми **New Application**, дай любое имя (например, "Казна сервера")
3. Слева выбери **Bot** → **Add Bot** (если ещё не создан)
4. На этой же странице:
   - Нажми **Reset Token** → скопируй токен (это секретный "пароль" бота,
     никому его не показывай и не выкладывай в открытый доступ)
   - Пролистай вниз до **Privileged Gateway Intents** и включи:
     - `SERVER MEMBERS INTENT`
     - `MESSAGE CONTENT INTENT`
5. Слева выбери **OAuth2** → **URL Generator**:
   - В Scopes отметь `bot` и `applications.commands`
   - В Bot Permissions отметь: `Administrator` (проще всего для старта;
     позже можно ограничить конкретными правами)
   - Скопируй сгенерированную ссылку внизу, открой её в браузере и
     добавь бота на свой сервер

## Шаг 2. Настроить проект локально

1. Скачай все файлы этого проекта себе на компьютер (сохрани папку
   `discord-bot` целиком)
2. Установи Python 3.10+ (если ещё нет): https://www.python.org/downloads/
   — при установке на Windows обязательно поставь галочку **Add Python to PATH**
3. Открой терминал (командную строку) в папке проекта и выполни:

   ```
   pip install -r requirements.txt
   ```

4. Переименуй файл `.env.example` в `.env` и впиши туда токен бота
   (тот, что скопировал на шаге 1):

   ```
   DISCORD_TOKEN=твой_настоящий_токен_сюда
   ```

5. Запусти бота:

   ```
   python bot.py
   ```

   Если всё правильно — в терминале появится "✅ Бот запущен как ...".
   На сервере бот станет "онлайн", и через минуту-две в Discord появятся
   все слэш-команды.

## Шаг 3. Настройка под себя

Кое-что нужно поправить под названия каналов/ролей твоего сервера:

- `cogs/welcome.py` → переменная `WELCOME_CHANNEL_NAME = "welcome"`:
  замени `"welcome"` на точное название своего канала для приветствий
- `cogs/roles.py` → переменная `AUTO_ROLE_NAME`: если хочешь, чтобы
  всем новым участникам сразу выдавалась роль, впиши её название,
  например `AUTO_ROLE_NAME = "Участник"`

После изменений просто перезапусти бота (`Ctrl+C`, затем снова
`python bot.py`).

## Шаг 4. Хостинг — чтобы бот работал 24/7

Пока ты запускаешь `python bot.py` у себя на компьютере, бот работает
только когда компьютер включён. Чтобы бот был онлайн постоянно, есть
бесплатные варианты:

### Railway (рекомендую для старта)

1. Зайди на https://railway.app и зарегистрируйся (можно через GitHub)
2. Создай новый проект → **Deploy from GitHub repo**
   (сначала загрузи папку проекта к себе на GitHub — можно через
   github.com, кнопка "Create new repository" → загрузить файлы)
3. В настройках проекта на Railway добавь переменную окружения:
   `DISCORD_TOKEN` = твой токен (не храни токен в самом коде на GitHub!)
4. Railway сам определит `Procfile` и запустит бота

Railway даёт ограниченное бесплатное количество часов в месяц — для
одного небольшого бота обычно этого достаточно.

### Альтернативы
- **Render.com** — похожий процесс, тоже есть бесплатный план
- **Собственный VPS** (например, от Timeweb, если сервер преимущественно
  российский) — надёжнее, но платно и чуть сложнее в настройке

## Если что-то не работает

- Бот не заходит в сеть → проверь токен в `.env`, он должен быть без
  кавычек и пробелов
- Слэш-команды не появляются → подожди пару минут, Discord иногда
  обновляет их с задержкой; либо перезайди в Discord
- Ошибка про "Privileged Intent" → вернись на Developer Portal и
  включи `SERVER MEMBERS INTENT` и `MESSAGE CONTENT INTENT` (шаг 1, пункт 4)

Если пришлёшь мне текст ошибки — разберём вместе.
